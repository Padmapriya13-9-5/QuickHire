This project is an end-to-end machine learning solution built using Jupyter Notebook for forecasting sales across different states. It uses multiple models such as ARIMA, Prophet, XGBoost, and LSTM to predict future values and compares their performance to select the best model automatically.

The workflow includes data preprocessing, feature engineering (lag features, rolling statistics, and time-based features), handling missing values, and evaluating models using standard error metrics.

The final system generates forecasts for the next 8 weeks and exposes predictions through a REST API using FastAPI.

 Highlights
1.Multiple ML & DL models comparison
2.Automatic best model selection
3.Time series feature engineering
4.End-to-end forecasting pipeline
5.API-based prediction system

Tools Used

Python, Pandas, NumPy, Scikit-learn, XGBoost, Prophet, TensorFlow, FastAPI
